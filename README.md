# WHAT IS?
There was a time when the Internet felt like somewhere to escape to. Now it is impossible to escape from.

Well Made Web seeks to chronicle any web page made in this spirt, where it may still be found. These selected websites hearken back to a time of wonder and discovery. Here live the wild and glorious pages from the web in all its ages; a peek over the walled gardens of social media. Originality and effort is welcomed, no matter its subject.

# WHAT IS INSIDE?
This repository is the complete archive of Well Made Web. It includes the `rsru` perl script used to construct the gallery from ENTRY files, as well as the entries and screenshots themselves.

# WHO IS IT FOR?
Mostly myself. I'll open the repo to the public maybe someday. I like what I've found and it's too good just to keep on my server.
