UK Game Shows [permalink]
If you ever wanted to know something about a British game show, you might think to check Wikipedia. Or perhaps the official websites of the BBC, ITV or C4. Think again - the power of amateur enthusiasm has instead given us this vast repository of game show knowledge. The website is packed with background information, production information, biographies of the hosts, bloopers, excursuses on notable episodes and details of when and how the game shows changed.

The website is still updated as of 2024, and the information it contains stretched back to the earliest days of broadcast television in Britain.

Some notable articles include: Countdown, Deal or No Deal, Masterchef and Catchphrase. One I recall from childhood is Raven. There are many, many more.

This site is a joy to read, even though one may be nowhere near as interested in game shows, merely encountering this website inspires the same devotion in others to create such a resource. It is a shame that it loses to Wikipedia in the search result rankings, a resource with sparser, plainer written articles on the same game shows.

Notably the website was built by one Tom Scott, who later found YouTube fame.
